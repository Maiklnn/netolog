# Резервное копирование картинок кошек в Яндекс.Диск

## Описание проекта
Программа для резервного копирования картинок с текстом с сайта cataas.com в облачное хранилище Яндекс.Диск.

## Требования
- Python 3.7+
- Аккаунт Яндекс.Диска
- Токен с Полигона Яндекс.Диска

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
```bash
pip install -r requirements.txt
3. запуск python main.py
