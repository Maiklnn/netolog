## Шаг 1. Подготовка среды и данных

Установите необходимые библиотеки: pandas, scikit-learn, matplotlib, seaborn, nltk.
Скачайте датасет. Загрузите CSV-файл в ноутбук с помощью pandas.

## Шаг 2. Разведочный анализ данных (EDA)

Изучите структуру датасета: просмотрите первые строки (`df.head()`), проверьте типы данных,
посчитайте пропуски. Постройте гистограмму распределения классов. Визуализируйте распределение
длин текстов. Сделайте выводы: какие классы доминируют? Есть ли дисбаланс?

## Шаг 3. Предобработка текста

Приведите тексты к нижнему регистру. Удалите знаки пунктуации и лишние символы с помощью
регулярных выражений. Удалите стоп-слова (NLTK stopwords). Опционально: примените лемматизацию.
Создайте новую колонку с обработанным текстом.

## Шаг 4. Разбиение данных

Разделите выборку на train и test в пропорции 80/20 с использованием `stratify` по метке класса.
Убедитесь, что распределение классов в train и test сохранено.

## Шаг 5. Векторизация

Используйте `sklearn.pipeline.Pipeline` для объединения векторизатора (`TfidfVectorizer`)
и классификатора в единый объект — это обязательное требование, гарантирующее отсутствие
утечки данных. Инициализируйте Pipeline с шагами `[('tfidf', TfidfVectorizer(...)),
('clf', НазваниеКлассаМодели(...))]`. Fit Pipeline выполняется только на train, transform
для test выполняется автоматически внутри Pipeline.

## Шаг 6. Обучение моделей

Обучите не менее двух классических ML-моделей. Для каждой модели используйте sklearn Pipeline
(TfidfVectorizer + классификатор). Каждый обучающий запуск оберните в MLflow run: зафиксируйте
параметры модели через `mlflow.log_param()` и метрики качества через `mlflow.log_metric()`.
Используйте `mlflow.set_experiment()` для именования эксперимента и `with mlflow.start_run():`
для запуска трекинга.

## Шаг 7. Нейросетевая модель

Реализуйте MLP в PyTorch: обучите модель, оцените метрики. Результаты обучения также
залогируйте через MLflow (`mlflow.log_param` / `mlflow.log_metric`) в рамках отдельного run,
чтобы сравнить нейросеть с классическими моделями в едином эксперименте.

## Шаг 8. Оценка качества

Для каждой модели рассчитайте: `accuracy_score`, `classification_report`
(precision, recall, F1 по каждому классу + macro и weighted). Постройте confusion matrix,
создайте сводную таблицу метрик для сравнения моделей.

## Шаг 9. Выводы

Выберите лучшую модель и обоснуйте выбор. Ответьте на вопросы: какие классы предсказываются
хуже всего и почему? Что можно сделать для улучшения? Подходит ли решение для production?
