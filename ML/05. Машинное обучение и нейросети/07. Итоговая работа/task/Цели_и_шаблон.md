# Цели, структура и шаблон итоговой работы

- Страница: https://netology.ru/profile/program/aiml-5/lessons/662425/lesson_items/3549973
- Время прочтения: 5 мин

## Цели итоговой работы

- Применить техники предобработки и векторизации текста (TF-IDF, Count Vectorizer)
  для подготовки датасета обращений пользователей к обучению.
- Обучить и сравнить классические модели ML (LogisticRegression, RandomForest, LinearSVC)
  с помощью scikit-learn для многоклассовой классификации текста.
- Правильно выбирать и интерпретировать метрики (accuracy, precision, recall,
  F1-macro/weighted) применительно к несбалансированным данным.
- Построить воспроизводимый ML-pipeline.
- Сформулировать выводы о применимости решения в реальном сервисе поддержки.
- Оформить проект в виде читаемого Jupyter Notebook с комментариями и README-файлом.

## Тема

Тема одинакова для всех: классификация обращений пользователей в службу технической
поддержки. Задача — построить модель, которая автоматически определяет тип обращения
(категорию) по тексту сообщения.

## Формат

Jupyter Notebook (.ipynb) с подробными комментариями и файлом README.md, опубликованные
в репозитории GitVerse. Код должен воспроизводиться от начала до конца без ошибок.

## Кейс

Вы — ИИ-инженер компании, которая получает сотни обращений пользователей в сутки.
Чтобы ускорить маршрутизацию заявок, руководство поставило задачу: обучить модель
автоматической классификации обращений по категориям.

Датасет: Customer Support Ticket Dataset (Kaggle). Содержит реальные тексты обращений
с метками категорий. **Шаблон задания** ссылается на
[adisongoh/it-service-ticket-classification-dataset](https://www.kaggle.com/datasets/adisongoh/it-service-ticket-classification-dataset)
(колонки `Document` / `Topic_group`) — именно он использован в работе.

## Структура итоговой работы

1. Введение. Постановка задачи, описание датасета, цели работы.
2. Загрузка данных. Импорт библиотек, загрузка CSV, первичный просмотр.
3. EDA. Распределение классов, длина текстов, выводы о качестве данных.
4. Предобработка текста. Очистка, нормализация, стоп-слова, лемматизация.
5. Извлечение признаков. TF-IDF, выбор и обоснование параметров.
6. Обучение моделей. Не менее двух моделей, stratified train/test.
7. Оценка качества. Таблица метрик, confusion matrix, выводы.
8. Сравнение моделей и выбор лучшей.
9. Нейросетевая модель MLP на PyTorch, сравнение с классическими.
10. Выводы и рекомендации.
