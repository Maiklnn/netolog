## Текст задания

В этом задании вы будете на позиции ML-инженера в банке. Коллега обучил три модели для кредитного
скоринга. Ваша задача — оценить их качество, выявить проблемы и дать рекомендацию о запуске в продакшн.

### Цели задания

- рассчитывать метрики качества (Accuracy, Precision, Recall, F1, ROC-AUC) и осознанно выбирать их под задачу;
- интерпретировать confusion matrix и ROC-кривые;
- диагностировать дефекты обучения: дисбаланс классов, утечку данных, переобучение;
- формулировать аргументированное заключение о применимости модели.

### Чек-лист подготовки к выполнению задания

- Вебинар «Разбор метрик на примерах»;
- Лонгрид «Зачем нужны метрики»;
- Лонгрид «Выбор метрик».

### Инструменты для выполнения работы

Установка библиотек: `pip install scikit-learn pandas numpy matplotlib seaborn`

### Задание

Откройте файл `student_template.ipynb` и последовательно выполните все части задания. Ячейки с
пометкой `# TODO` требуют вашего кода или текстового ответа. Остальные ячейки запустите без изменений.

1. **Загрузка данных и первичный анализ** — изучите датасет, постройте распределение классов, опишите дисбаланс.
2. **Расчёт метрик** — обоснуйте выбор метрик. Вычислите Accuracy, Precision, Recall, F1, ROC-AUC;
   выведите `classification_report`.
3. **Визуализация и интерпретация** — постройте confusion matrix и ROC-кривые для всех трёх моделей;
   проведите письменный анализ.
4. **Диагностика проблем** — выявите и подтвердите дисбаланс классов, утечку данных, переобучение.
5. **Итоговое заключение** — заполните таблицу проблем, сформулируйте рекомендацию и ограничения.

### Как выполнять задание

- **Шаг 1. Подготовка.** Установите библиотеки, откройте `student_template.ipynb`.
  Если выполняете в Google Colab, шаг 1 можно пропустить — все библиотеки установлены по умолчанию.
- **Шаг 2. Запуск базового кода.** Запустите все ячейки без `TODO` (импорты, данные, обучение моделей).
- **Шаг 3. Выполнение заданий.** Последовательно выполняйте части 1–5. Не пропускайте — они связаны.
- **Шаг 4. Письменные ответы.** Текстовые ответы пишите в ячейках Markdown прямо в ноутбуке.
- **Шаг 5. Самопроверка.** Откройте `reference_solution.ipynb` и сверьтесь с чек-листом.

## Структура шаблона (что нужно заполнить)

| Часть | Задача | Баллы |
|-------|--------|-------|
| 1 | Загрузка данных и анализ баланса классов | 15 |
| 2 | Расчёт метрик | 25 |
| 3 | Визуализация и интерпретация | 25 |
| 4 | Диагностика проблем | 25 |
| 5 | Итоговое заключение | 10 |

- **1.1 (5 б.)** — количество и доля каждого класса, bar plot, комментарий о дисбалансе.
- **2.1 (5 б.)** — почему accuracy вводит в заблуждение при дисбалансе; какие метрики важнее для
  кредитного скоринга; когда важнее Precision, а когда Recall.
- **2.2 (15 б.)** — для каждой модели Accuracy, Precision, Recall, F1, ROC-AUC на тестовой выборке,
  итоговая таблица.
- **2.3 (5 б.)** — `classification_report` для каждой модели, акцент на метриках класса `1`.
- **3.1 (10 б.)** — матрицы ошибок для трёх моделей (1×3 subplots); какой тип ошибки (FP или FN)
  критичнее для банка.
- **3.2 (10 б.)** — ROC-кривые всех трёх моделей на одном графике, линия случайного классификатора,
  AUC в легенде, подписи осей.
- **3.3 (5 б.)** — какая модель показывает лучший AUC; может ли высокий AUC скрывать проблемы; пример.
- **4.1 (5 б.)** — сравнить долю предсказанных дефолтов с реальной; обучить
  `LogisticRegression(class_weight='balanced')` и сравнить Recall.
- **4.2 (10 б.)** — сравнить метрики Модели B на train и test; объяснить, что пошло не так и почему
  это критично для продакшна.
- **4.3 (10 б.)** — кривые обучения для Модели C (`learning_curve`, `scoring='roc_auc'`, `cv=5`);
  по каким признакам на графике видно переобучение.
- **Часть 5 (10 б.)** — сводная таблица проблем, рекомендация, ключевые ограничения.
