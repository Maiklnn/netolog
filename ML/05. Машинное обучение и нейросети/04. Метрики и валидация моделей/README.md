### Часть 3 — визуализация

- Confusion matrix 1×3: A — TN 1048 / FP 7 / FN 105 / TP 90; B — 1055 / 0 / 0 / 195;
  C — 1049 / 6 / 39 / 156.
- ROC-кривые трёх моделей на одном графике с линией случайного классификатора и AUC в легенде.
- Письменная интерпретация: FN для банка критичнее FP; высокий AUC может скрывать утечку,
  дисбаланс, плохую калибровку и переобучение.

### Часть 4 — диагностика

- **Дисбаланс.** Модель A предсказывает 7,8 % дефолтов при реальных 15,6 %.
  `class_weight='balanced'` поднимает Recall 0,462 → 0,728 при падении Precision 0,928 → 0,406.
- **Утечка.** Модель B обучена на `X, y` (вместе с тестом) → 1,0 на train и test. Честная модель
  на `X_train` даёт на тесте AUC 0,951 и Recall 0,703; 5-fold CV ROC-AUC ≈ 0,956.
- **Переобучение.** `learning_curve` для C: train ROC-AUC = 1,0 на всех размерах, CV 0,847 → 0,966,
  зазор 0,153 → 0,034; train accuracy 1,000 против test 0,964.

без утечки, C регуляризовать и откалибровать, A — baseline) и ключевые ограничения.
