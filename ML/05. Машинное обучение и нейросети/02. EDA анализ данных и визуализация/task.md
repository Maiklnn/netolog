## Описание задания

Вам необходимо провести анализ одного из реальных источников данных, используя Python и соответствующие библиотеки для анализа данных.

Список наборов данных, из которых можно выбрать, находится в списке инструментов.

После выбора датасета нужно выполнить задание:

### 1. Первичное ознакомление с данными

Выберите один из предложенных датасетов и загрузите его в среду анализа (Jupyter Notebook / PyCharm / VSC). Определите:

- общее количество строк и столбцов;
- типы данных каждого признака;
- наличие дубликатов (и их долю).

Кратко опишите, что представляет собой датасет: какая предметная область, что является наблюдением (строкой), что — признаками. Обоснование можно привести в формате текстовой ячейки.

### 2. Разведочный анализ данных (EDA)

Проведите анализ отдельно для числовых и категориальных признаков.

#### 2.1. Числовые признаки

Для каждого числового признака рассчитайте:

- долю пропущенных значений;
- минимум и максимум;
- среднее и медиану;
- дисперсию;
- квантили 0.1 и 0.9;
- первый и третий квартиль.

Дополнительно:

- выявите выбросы (через IQR);
- укажите признаки с подозрительными распределениями (перекос, длинные хвосты).

#### 2.2. Категориальные признаки

Для каждого категориального признака определите:

- долю пропусков;
- количество уникальных значений;
- наиболее часто встречающееся значение (моду).

Дополнительно:

- найдите признаки с высокой кардинальностью (много уникальных значений);
- выявите потенциально «шумные» категории (редкие значения).

### 3. Визуальный анализ данных

Постройте не менее четырёх осмысленных графиков, которые:

- раскрывают важную закономерность в данных;
- или демонстрируют проблему (например, выбросы, дисбаланс, зависимость признаков).

**Важно:** просто «построить гистограмму» недостаточно — необходимо:

- объяснить, почему выбран именно этот график;
- сформулировать конкретный вывод на его основе; график должен быть полезным для анализа;
- графики должны быть построены для категориальных и числовых признаков.

## Инструкция к выполнению

1. Выберите один из предложенных датасетов.
2. Скачайте данные и загрузите их в среду анализа (Jupyter Notebook / PyCharm / VS Code).
3. Подключите необходимые библиотеки (pandas, numpy, matplotlib, seaborn).
4. Выведите первые строки датасета (`head()`), чтобы понять его структуру.
5. Определите размер датасета (`shape`).
6. Проверьте типы данных (`dtypes`, `info()`).
7. Найдите дубликаты, при наличии — оцените их долю.
8. Дайте краткое текстовое описание датасета: что является объектом наблюдения; какие признаки представлены и что они означают.
9. Разделите признаки на:
   - числовые (int, float);
   - категориальные (object, category, bool).
10. При необходимости приведите типы данных к корректному виду.
11. Для каждого числового признака:
    - рассчитайте статистики (mean, median, var, min, max, quantile);
    - вычислите долю пропусков (`isna().mean()`).
12. Определите выбросы:
    - рассчитайте IQR;
    - выделите значения за пределами допустимого диапазона.
13. Проанализируйте распределения:
    - выявите асимметрию, длинные хвосты, аномальные значения;
    - зафиксируйте наблюдения в текстовых комментариях.
14. Для каждого категориального признака:
    - рассчитайте долю пропусков;
    - определите количество уникальных значений;
    - найдите моду.
15. Сделайте краткие выводы по каждому признаку.
16. Постройте не менее 4 графиков:
    - для числовых признаков (гистограммы, boxplot, scatterplot и др.);
    - для категориальных признаков (barplot и др.).
17. Для каждого графика:
    - укажите цель его построения;
    - интерпретируйте результат;
    - сформулируйте конкретный вывод.
18. Обратите внимание на:
    - выбросы;
    - дисбаланс категорий;
    - зависимости между признаками.
19. Обобщите результаты анализа:
    - какие проблемы есть в данных (пропуски, выбросы, шум);
    - какие признаки требуют обработки;
    - есть ли ограничения для использования данных.
20. Сделайте вывод о пригодности датасета для анализа или обучения моделей.

## Критерии оценки задания

### «Зачёт»

- Датасет загружен, описаны его суть, размер, типы данных и дубликаты.
- Рассчитаны все статистики. Корректно найдены пропуски, выбросы и особенности распределений.
- Построено от 4 разных графиков. Каждый обоснован и завершается логичным выводом.
- Выделены главные проблемы данных (пропуски, дисбаланс и т.д.) и оценена их пригодность для дальнейшей работы.
- Аккуратный, читаемый код. Ноутбук имеет чёткую структуру и подробные текстовые комментарии.

### «На доработку»

- Пункты задания пропущены или сделаны поверхностно, «для галочки».
- Неверно рассчитаны или интерпретированы статистики, не замечены явные проблемы (пропуски, выбросы).
- Графики построены без цели, выводы отсутствуют или не связаны с картинкой.
- Нет финальной оценки качества датасета.
- Запутанный код, отсутствие комментариев, нарушена логика повествования.

### «Незачёт»

Ставится в крайнем случае, если вы присылаете пустое или недоработанное задание во второй раз после отправки работы на доработку.
