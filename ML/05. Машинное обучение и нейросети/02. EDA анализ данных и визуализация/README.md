# Практика EDA — Hotel booking demand

Практическое задание курса aiml-5 «Машинное обучение и нейросети» (модуль «EDA: анализ данных и визуализация»).

## Файлы

| Файл | Описание |
|---|---|
| `EDA_hotel_bookings.ipynb` | Готовый выполненный ноутбук со всеми разделами задания и встроенными графиками |
| `data/hotel_bookings.csv` | Исходный датасет (119 390 строк × 32 признака) |

## Что сделано в ноутбуке

1. **Первичное ознакомление** — размер, типы данных, полные дубликаты (31 994 / 26.8%), описание предметной области и расшифровка признаков.
2. **EDA числовых признаков** — пропуски, min/max, среднее, медиана, дисперсия, квантили 0.1/0.9, Q1/Q3, выбросы по IQR, асимметрия и эксцесс, логические аномалии.
3. **EDA категориальных признаков** — пропуски, число уникальных значений, мода и её доля, высокая кардинальность, редкие категории.
4. **Визуальный анализ** — 6 графиков, у каждого указаны цель, интерпретация и вывод:
   - распределение `adr` и выбросы (гистограмма + boxplot);
   - доля отмен по типу отеля;
   - связь `lead_time` с отменой;
   - корреляционная матрица числовых признаков;
   - сезонность бронирований и отмен по месяцам;
   - топ-15 стран и дисбаланс категорий.
5. **Итоговые выводы** — проблемы качества данных, признаки для обработки, ограничения и оценка пригодности датасета.

## Ключевые результаты

- Целевая переменная `is_canceled`: 63.0% / 37.0% — умеренный дисбаланс.
- Полные дубликаты: 31 994 строки (26.8%).
- Пропуски: `company` — 94.3%, `agent` — 13.7%, `country` — 0.4%, `children` — 4 значения.
- Выявлена утечка целевой переменной: `reservation_status` и `reservation_status_date` полностью связаны с `is_canceled` — их нужно удалить перед моделированием.
- `adr` сильно скошен (skew = 10.5), 3 793 выброса по IQR, есть отрицательные значения.
- Сильнейшие связи с отменой: `lead_time` (+0.29), `total_of_special_requests` (−0.24), `required_car_parking_spaces` (−0.20), `booking_changes` (−0.14).

**Вывод:** датасет пригоден для обучения моделей после удаления дубликатов и утечек, обработки выбросов `adr`, группировки редких категорий и кодирования сезонности.
