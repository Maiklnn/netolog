## Данные

**Telco Customer Churn** — открытый демонстрационный набор IBM. Задача — бинарная
классификация: предсказать отток клиента (`Churn`: `Yes` / `No`) по демографии, подключённым
услугам, условиям договора и числовым показателям (`tenure`, `MonthlyCharges`, `TotalCharges`).
Персональных данных нет: `customerID` — случайный идентификатор, в ноутбуке он удаляется.
Источник:
<https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv>.

Классы несбалансированы: 73,46% «не уйдёт» / 26,54% «уйдёт».

## Что сделано

1. **Описание задачи и данных** — бизнес- и ML-постановка, группы признаков, целевая
   переменная, выбор метрик.
2. **Предобработка:**
   - `TotalCharges` приведён из строки в число; найдено 11 пропусков (все — клиенты
     с `tenure = 0`), заполнены нулём: новый клиент ещё не пользовался услугами, поэтому
     накопленных платежей у него нет (медиана ≈1 400 создала бы искажённое наблюдение);
     все 7 043 строки сохранены;
   - проверены дубликаты строк и повторы `customerID` — нет;
   - выбросы проверены правилом 1,5·IQR по трём числовым признакам — не найдено,
     большие `TotalCharges` оставлены как легитимные значения;
   - `customerID` удалён как идентификатор, `Churn` закодирован в 0/1;
   - `train_test_split`: 80/20, `random_state=42`, `stratify=y`;
   - числовые признаки стандартизированы `StandardScaler` (fit только на train — без утечки);
   - категориальные закодированы `pd.get_dummies(drop_first=True)` с выравниванием колонок
     теста по train; итог — 30 признаков, пропусков нет.
3. **Модель:** `LogisticRegression(max_iter=1000, random_state=42)`, обучение `.fit()`,
   предсказания `.predict()` и вероятности `.predict_proba()`.
4. **Оценка:** accuracy, precision, recall, F1, ROC-AUC, матрица ошибок,
   `classification_report`, сравнение первых 15 фактов и прогнозов.
5. **Проверка вырожденности:** распределение прогнозов (оба класса присутствуют) и
   сравнение с `DummyClassifier(most_frequent)`.
6. **Дополнительно:** интерпретация коэффициентов и эксперимент с `class_weight="balanced"`.
7. **Вывод** о пригодности модели и направлениях развития.
