## Введение

Уважаемые студенты!

В работе дата-сайентиста мало просто «скормить» данные алгоритму. Главная проблема — у них нет
понимания, работает их модель на самом деле или просто угадывает. Модель может предсказывать
всем клиентам один и тот же результат, и формально метрика будет неплохой, но пользы от такой
модели ноль. В этом задании вы научитесь видеть такие подвохи и честно оценивать качество своих
решений.

Выполнив это задание, вы:

- освоите базовые этапы предобработки данных для машинного обучения: устранение пропусков,
  кодирование категориальных признаков и разделение набора данных на обучающую и тестовую
  выборки для обучения модели;
- изучите стандартный рабочий процесс в библиотеке scikit learn: создание экземпляра модели,
  её обучение на исторических данных с помощью метода `.fit()` и формирование прогнозов для
  новых данных через метод `.predict()`;
- научитесь объективно оценивать качество модели: рассчитывать ключевые метрики и выявлять
  потенциальные проблемы (например, вырожденное поведение модели, когда она выдаёт одинаковый
  прогноз для всех объектов).

## Описание задания

Вам необходимо выполнить полный цикл обучения классической ML-модели в scikit-learn.
Необходимо последовательно выполнить следующие шаги:

1. Выберите открытый набор данных без персональных информации (например, Kaggle), загрузите его
   и выполните минимальную предобработку: обработайте пропуски и выбросы, закодируйте
   категориальные признаки в числа, разделите данные на обучающую и тестовую выборки с помощью
   `train_test_split`.
2. Постройте и обучите как минимум одну модель машинного обучения для решения задачи
   классификации или регрессии (линейная/логистическая регрессия), путем вызова метода `.fit()`
   на обучающих данных.
3. Получите предсказания каждой модели на тестовой выборке через метод `.predict()`, рассчитайте
   базовые метрики качества.
4. Проанализируйте полученную метрику, оцените качество работы выбранного алгоритма на новых
   данных и сформулируйте итоговый вывод о пригодности данной модели для решения поставленной
   задачи, оформив все шаги и результаты в Jupyter Notebook с обязательными пояснениями
   в Markdown-ячейках.

## Инструкция к выполнению

1. Создайте новый Jupyter Notebook и в первой ячейке импортируйте необходимые библиотеки.
   Например: pandas для работы с таблицами, numpy для вычислений, а также нужные модули
   из sklearn.
2. Загрузите выбранный вами набор данных в DataFrame с помощью `pd.read_csv()` или функции
   загрузки из `sklearn.datasets`, если используете встроенный датасет.

   Пример импорта встроенного датасета на примере Iris (классификация цветов ириса):

   ```python
   from sklearn.datasets import load_iris
   iris = load_iris()
   ```

3. Выведите первые 5 строк таблицы методом `.head()`, чтобы визуально оценить структуру данных,
   и вызовите `.info()`, чтобы проверить типы колонок и наличие пропусков.
4. Опишите в Markdown-ячейке суть вашего датасета: какая стоит задача, признаки и целевая
   переменная.
5. Проверьте количество пропущенных значений в каждой колонке с помощью `.isnull().sum()` и как
   с ними поступить: заполнить средним/медианой или удалить строки, если пропусков мало.
6. Если в данных есть текстовые (категориальные) колонки, преобразуйте их в числа, используя
   `LabelEncoder` из `sklearn.preprocessing` или метод `pd.get_dummies()`.
7. Отделите целевую переменную (то, что предсказываем) в отдельную переменную `y`, все признаки
   соберите в переменную `X`.
8. Импортируйте функцию `train_test_split` из `sklearn.model_selection` и разделите данные на
   обучающую (`X_train`, `y_train`) и тестовую (`X_test`, `y_test`) части в пропорции 80/20
   или 70/30.
9. Обязательно укажите параметр `random_state=42` при разделении, чтобы результаты можно было
   воспроизвести при повторном запуске кода.
10. Выберите один алгоритм машинного обучения, соответствующий вашей задаче
    (`LogisticRegression` для классификации или `LinearRegression` для регрессии),
    и импортируйте его класс.
11. Создайте объект выбранной модели, присвоив его переменной (например,
    `model = LogisticRegression()`), при необходимости задав базовые параметры.
12. Обучите модель на обучающих данных, вызвав метод `.fit(X_train, y_train)`, и дождитесь
    завершения процесса обучения.
13. Получите предсказания модели на тестовой выборке, вызвав метод `.predict(X_test)` и сохранив
    результат в переменную `y_pred`.
14. Импортируйте подходящую метрику качества из `sklearn.metrics`: `accuracy_score` для
    классификации или `mean_absolute_error` / `r2_score` для регрессии.
15. Рассчитайте значение метрики, передав в неё реальные значения из теста (`y_test`) и полученные
    предсказания (`y_pred`), и выведите результат на экран.
16. Выведите первые 10–15 значений из `y_test` и соответствующие им предсказания из `y_pred`,
    чтобы визуально сравнить, насколько близко модель угадала ответы.
17. Проверьте распределение предсказаний: убедитесь, что модель не выдает одно и то же значение
    для всех объектов (что говорит о нерабочем состоянии модели).
18. Напишите в финальной Markdown-ячейке вывод: какая модель использовалась, какую метрику
    получили, хороший ли это результат с вашей точки зрения и почему вы так считаете.
19. Проверьте весь ноутбук на наличие ошибок выполнения (Restart & Run All) и убедитесь, что
    каждая ячейка с кодом имеет поясняющий текст сверху или снизу.
