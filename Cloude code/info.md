# Основные slash-команды

/init  
Создать CLAUDE.md  

/model  
Выбрать модель  

/compact  
Сжать контекст  

/clear  
Очистить контекст  

/cost  
Стоимость сессии  

/resume  
Откат челконита  

/resume  
Проживать сессию  

/btw  
Быстрая вопрос  

/context  
Статус контекста  

/sandbox  
Включить ресторан  

/config  
Настройки  

/doctor  
Диагностика Clode Code: нет ли каких-либо проблем?
