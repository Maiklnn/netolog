# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Назначение каталога

`Cloude code` — это папка с заметками/шпаргалками по самому Claude Code, часть более
крупного древа документации (`D:\Документы\Manual\Нитология`). **Здесь нет исходного кода,
системы сборки или тестов** — анализировать «архитектуру» не из чего.

Содержимое:
- `info.md` — русские заметки о slash-командах Claude Code (часть описаний近似ательна/содержит опечатки).
- `прощание.txt`, `Redmi` — служебные/текстовые файлы без кода.
- `Cloude code.lnk` — ярлык Windows.
- `.idea/` — конфигурация IntelliJ (не относится к какому-либо проекту в этом каталоге).

## Работа в этом каталоге

- Команды сборки/линта/тестов отсутствуют — выполнять нечего.
- При правках ограничивайтесь редактированием текстовых заметок (`info.md` и т.п.).
- Реальный код (JS-файлы, n8n-воркфлоу, `memory-bank/`) находится в **родительском**
  каталоге `D:\Документы\Manual\Нитология` — если задача касается кода, уточните у пользователя,
  в каком каталоге работать, прежде чем выходить за пределы текущего.
